# No-One-Spoke-Today

No One Spoke Today

아직 아무 일도 일어나지 않았다.

그러나, 말들은 이미 오가고 있었다.

📌 프로젝트 소개

오늘, 아무 말도 하지 않았다는
콘솔 창에서 진행되는 대화 중심 사회 시뮬레이션 게임입니다.

플레이어는 이동하는 도시의 리더로서
사람들과 직접 대화를 나누고,
그들의 말과 태도, 그리고 침묵을 통해
도시의 분위기와 미래를 판단하고 개입합니다.

이 게임에는 명확한 정답이 없습니다.
당신이 듣지 못한 말들 속에서
도시는 이미 변화하고 있을 뿐입니다.

🧠 게임 핵심 컨셉

🏙 이동하는 도시

도시는 정착하지 않고 끊임없이 이동합니다

외부 도시와의 조우, 충돌, 외교가 자연스럽게 발생합니다

👥 살아있는 사람들

모든 시민은 고유한 성향과 감정 상태를 가집니다

불안, 분노, 희망, 체념 등은 말과 행동에 드러납니다

🗣 대화가 곧 게임 플레이

정보를 숫자로 요약하지 않습니다

사람들의 말투, 표현, 망설임으로 상황을 파악해야 합니다

⏱ 시간 기반 하루 시스템

하루는 제한된 실제 시간으로 구성됩니다

누구를 만나고, 누구를 지나칠지 선택해야 합니다

🎮 게임 플레이 방식
▶ 하루의 흐름

도시 분위기 서술 출력

현재 주목할 만한 인물들의 대사 등장

플레이어는:

특정 인물과 대화

갈등 중재

외부 도시와 통신

혹은 아무것도 하지 않을 수도 있음

시간이 종료되면 하루가 마무리되고,
플레이어가 개입하지 않은 사건들은 백그라운드에서 진행됩니다

🧍 사람과 사회

각 시민은 다음과 같은 요소를 가집니다:

성향: 이성적, 충동적, 공격적, 회피적 등

감정 상태: 불안, 분노, 희망, 냉소 등 (중첩 가능)

사회적 태도: 충성, 관망, 불신, 반감

행동 압력: 억제 → 동요 → 임계 → 행동

이 개인들의 상태가 모여
도시 전체의 분위기와 사건 발생 확률을 결정합니다.

🌐 이벤트 스케일

👤 개인 ↔ 개인 갈등

👥 무리 ↔ 무리 충돌

🏙 도시 ↔ 도시 외교 / 충돌 / 인구 이동

⚠ 반역, 이탈, 결집, 붕괴

모든 사건은
대화와 분위기의 누적 결과로 발생합니다.

🖥 인터페이스

텍스트 기반 콘솔 UI

선택지 중심이 아닌 자유 대화 흐름

상태 수치는 직접적으로 드러나지 않으며,
대부분은 서술과 대사로 암시됩니다

🧩 개발 목표

“모든 사람이 살아있다고 느껴지는” 시뮬레이션

관리 게임이 아닌 관찰과 개입의 게임

숫자보다 말이 중요한 사회 시스템 구현
